# Primitive DB

Консольная база данных на Python.

## Управление таблицами

Доступные команды:
- `create_table <имя_таблицы> <столбец1:тип> ...` — создать таблицу (типы: int, str, bool).
- `drop_table <имя_таблицы>` — удалить таблицу.
- `list_tables` — показать список таблиц.
- `help` — справка.
- `exit` — выход.
