# Primitive DB

Консольная база данных на Python с поддержкой CRUD-операций, валидацией типов и сохранением данных в JSON.

## Установка и запуск

Проект использует пакетный менеджер [uv].

1. Клонируйте репозиторий и перейдите в папку проекта:
    git clone https://github.com/alexandrakeystone-bit/project-2_Gladkaya_26-555.git
    cd project-2_Gladkaya_26-555

2. Синхронизируйте зависимости и установите пакет как CLI-инструмент:
    uv sync
    uv tool install . --force

3. Запустите базу данных:
    database

## Управление таблицами
Доступные команды для работы со структурой базы данных:
- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать таблицу. Поддерживаемые типы: int, str, bool. Столбец ID добавляется автоматически.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `list_tables` — показать список всех таблиц.
- `help` — вывести справку по всем командам.
- `exit` — выход.

## CRUD-операции (работа с данными)
-`insert into <имя_таблицы> values (<значение1>, ...)` — создать запись. Количество значений должно совпадать с количеством столбцов (без учета ID).
-`select from <имя_таблицы> [where <столбец> = <значение>]` — прочитать все записи или отфильтровать по условию.
-`update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновить запись.
-`delete from <имя_таблицы> where <столбец> = <значение>` — удалить запись.
-`info <имя_таблицы>` — вывести структуру таблицы и количество записей.

## Обработка ошибок и безопасность
Все операции обернуты в декоратор, который перехватывает исключения и выводит понятное сообщение, не завершая программу аварийно.
Опасные операции защищены декоратором confirm_action. Перед выполнением программа запросит подтверждение ([y/n]).
Время выполнения операций insert и select логируется с помощью декоратора log_time.
Результаты select кэшируются с помощью замыкания (create_cacher), чтобы повторные запросы выполнялись мгновенно.
